## 📌 O que é o Entra21?

O **Entra21** é um programa de qualificação profissional em tecnologia realizado em **Blumenau - SC**, com foco em preparar jovens para o mercado de trabalho na área de desenvolvimento de software.

Estou participando da turma de **Java**, onde além do back-end, também exploramos fundamentos de **JavaScript, HTML e CSS**.

> *Este repositório não é um portfólio de projetos prontos — é algo mais honesto que isso: é o registro real da minha evolução, aula por aula, desde o primeiro `System.out.println` até os desafios mais complexos.*

## 🧠 O que estou aprendendo com isso?

Mais do que sintaxe e exercícios, este programa está me ensinando algo que nenhum tutorial ensina:

- **Disciplina** — aparecer todos os dias, mesmo quando é difícil
- **Raciocínio lógico** — resolver problemas do zero, sem copiar solução
- **Evolução real** — olhar para o código do início e ver o quanto evoluí
